# Netflix-Dataset
# Task 1: Data Cleaning & Preprocessing — Netflix Dataset

## Project Overview

This project focuses on cleaning, transforming, and preparing the Netflix dataset for further data analysis. Using Python and Pandas, the project identifies missing values and duplicate records, standardizes inconsistent data formats, transforms categorical and date-related columns, and produces a clean dataset ready for exploratory data analysis (EDA).

This project demonstrates essential data preprocessing skills required for data analytics and data science workflows.

## Objectives

The main objectives of this project are to:

- Load and explore the Netflix dataset using Pandas.
- Identify missing values and duplicate records.
- Handle missing data appropriately.
- Standardize text values and inconsistent formats.
- Convert date columns into appropriate datetime formats.
- Transform categorical variables.
- Extract useful features from date and duration columns.
- Validate the cleaned dataset.
- Export the processed data for further analysis.

## Dataset

**Dataset name:** Netflix Dataset



The dataset contains information about movies and television shows available on Netflix.

### Key Features

| Column | Description |

| `show_id` | Unique identifier for each title |
| `type` | Type of content: Movie or TV Show |
| `title` | Title of the movie or TV show |

| `country` | Country associated with the title |
| `date_added` | Date the title was added to Netflix |
| `release_year` | Year the title was released |
| `rating` | Content rating |
| `duration` | Movie runtime or number of TV show seasons |
| `listed_in` | Genres or categories associated with the title |

*Note: The dataset's actual columns and available records may vary depending on the version downloaded.*

## Project Workflow

### 1. Data Loading

Imported the Netflix dataset into a Pandas DataFrame using `pd.read_csv()`.

### 2. Data Exploration

Examined the dataset's structure, column names, data types, dimensions, and descriptive statistics.

### 3. Missing Value Analysis

Identified missing values in each column and calculated their percentages to understand the extent of missing data.

### 4. Duplicate Detection and Removal

Identified duplicate records and removed exact duplicate rows to improve data consistency.

### 5. Missing Value Treatment

Handled missing values in selected text columns, including `director`, `cast`, `country`, `rating`, `duration`, `listed_in`, and `description`, by replacing them with `"Unknown"`.

Missing date values were preserved as missing rather than replaced with invented dates.

### 6. Data Standardization

Standardized text fields by removing unnecessary whitespace and normalizing selected categorical values, including content types and ratings.

### 7. Date Transformation

Converted the `date_added` column into a datetime format and extracted additional features:

- `date_added_year`
- `date_added_month`
- `date_added_month_name`

These features support time-based analysis of Netflix content additions.

### 8. Categorical Data Transformation

Converted selected columns, such as `type` and `rating`, to Pandas categorical data types to represent their discrete values appropriately.

### 9. Duration Feature Engineering

Extracted numerical duration values and their corresponding units from the `duration` column.

For example:

- `90 min` becomes `duration_value = 90` and `duration_unit = min`.
- `2 Seasons` becomes `duration_value = 2` and `duration_unit = Season`.

This transformation supports separate analysis of movie runtimes and TV show seasons.

### 10. Data Validation and Export

Validated the cleaned dataset by checking its dimensions, remaining duplicate records, missing values, and data types.

Exported the processed dataset to a new CSV file for further analysis.
